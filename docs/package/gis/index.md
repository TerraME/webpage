This package has funcionalities to create and manage a database to be used by any model in TerraME.  

## Types

| Type | Description |
|---|---|
|[Layer](./types/layer.md)|A [Layer](./types/layer.md) representing a geospatial dataset stored in a given data source.|
|[Project](./types/project.md)|[Project](./types/project.md) is a concept to describe all the data to be used by a given model.|
|[TerraLib](./types/terralib.md)|Type to access [TerraLib](./types/terralib.md).|
