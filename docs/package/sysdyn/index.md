# System Dynamics

  
**Version:** 0.8.6  
**License:** GPL  
**Release:** 20 August 2020  
**Authors:** Gilberto Camara and Pedro R. Andrade  
**Depends:** terrame (>= 2.0), sci (>= 0.3)  
  
  

Implements a System Dynamics framework.  

## [Models](models.md)

|Model|Description|
|---|---|
|[ChaoticGrowth](models.md#ChaoticGrowth)|A Model that describes a chaotic population growth.|
|[Coffee](models.md#Coffee)|Simple model that simulates the temperature of a cup of coffee.|
|[Daisyworld](models.md#Daisyworld)|An implementation of the daisy world model.|
|[Dam](models.md#Dam)|A water in the dam model.|
|[Homeostasis](models.md#Homeostasis)|A model to show homeostasis taking place.|
|[LimitedGrowth](models.md#LimitedGrowth)|A model that simulates limited growth.|
|[Lorenz](models.md#Lorenz)|Classic Lorenz Model to study chaos.|
|[MonoLake](models.md#MonoLake)|A model for the Mono Lake problem.|
|[PopulationGrowth](models.md#PopulationGrowth)|Simple model that simulates the growth of two populations.|
|[PredatorPrey](models.md#PredatorPrey)|Model that implements predatory-prey dynamics.|
|[RandomWalk](models.md#RandomWalk)|Simple random walk model, where a given value can be added by one or subtracted by one randomly.|
|[RoomTemperature](models.md#RoomTemperature)|Simple model that simulates the temperature of three rooms.|
|[SIR](models.md#SIR)|A Susceptible-Infectious-Recovered (SIR) Model to study epidemics.|
|[Tub](models.md#Tub)|A simple water in the tub model.|
|[Yeast](models.md#Yeast)|A yeast growth model.|
