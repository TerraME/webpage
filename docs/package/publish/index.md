# Publishing Model Results

  
**Version:** 0.6  
**License:** LGPL-3  
**Release:** 04/30/2025  
**Authors:** Heitor Carneiro and Pedro R. Andrade  
**Depends:** terrame (>= 2.0)  
  
**URL:** [https://github.com/TerraME/publish](https://github.com/TerraME/publish)  
  

This package allows one to export the outputs of different Model scenarios to a web server.  

## Types

|Type|Description|
|---|---|
|[Application](./types/application.md)|Creates a web page to visualize the published data.|
|[List](./types/list.md)|A list of [View](./types/view.md) objects.|
|[Report](./types/report.md)|Creates a page with data information.|
|[View](./types/view.md)|[View](./types/view.md) is an object that contains the information of the data to be visualized.|
