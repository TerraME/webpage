## **link** 

Creates a link to a webpage.  
  

### Arguments

- **#1**: A string with the webpage address.
- **#2**: A string with the text to be shown with the link in the [Application](../types/application.md).

### Usage

```
link("www.wikipedia.org", "wikipedia")
```
